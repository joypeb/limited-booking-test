# 규칙·테스트·증거 추적표

규칙 한 행은 "규칙(계획서 절) → 구현 대상 → 검증 테스트 → 실행 명령 → 증거 문서" 순서로 읽는다. 대상 경로는 저장소 루트 기준이고 테스트는 `Class#method`, 명령은 `backend/`에서 실행한다. 테스트 종류에 따라 태스크가 다르다: Spring 없는 `*Test`는 `test`, 일반 `*IT`는 `integrationTest`, contract 태그는 `contractTest`, property 태그는 `propertyTest`, 순수 규칙 변이는 `mutationSmoke`다. 실제 실행 결과와 수치는 증거 열의 문서에서 확인한다(이 표는 연결만 기록하며 통과를 주장하지 않는다). 정적 검사는 저장소 루트의 `scripts/check-traceability.sh`로 하며 파일·메서드·태스크·링크의 존재만 확인하고 의미상 타당성은 증명하지 않는다.
